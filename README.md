## Overview

This project predicts household electricity consumption using Machine Learning and provides intelligent energy optimization insights through an interactive dashboard.

The system analyzes historical energy consumption data, forecasts future usage, estimates monthly electricity costs, identifies unusual consumption patterns, and provides AI-based recommendations for energy optimization.

## Features

* Energy Consumption Prediction
* Monthly Electricity Bill Estimation
* Anomaly Detection using Isolation Forest
* AI Energy Assistant
* Historical Energy Analytics Dashboard
* Downloadable Reports
* Interactive Streamlit Interface

## Technologies Used

* Pandas
* NumPy
* Scikit-Learn
* Streamlit

## Dataset

UCI Household Power Consumption Dataset

Dataset Size:

* More than 2 million household electricity records

## Machine Learning Model

Random Forest Regressor

Evaluation Metric:

* Mean Absolute Error (MAE): 0.23

## Key Functionalities

### Energy Prediction

Predicts future household energy consumption using historical usage patterns.

### Cost Estimation

Estimates monthly electricity costs based on predicted energy consumption.

### Anomaly Detection

Detects unusual energy consumption spikes using Isolation Forest.

### AI Assistant

Provides intelligent recommendations for improving energy efficiency.
